# Agent Result Handoff

This is the compact **outbound result** for work received through `implementation-packet.md`; link to that inbound packet instead of duplicating it.

```md
## Assignment
- Inbound implementation packet:
- Objective:
- Owned files/area and editor status:

## Result
- Decisions/findings (max 10):
- Changes made:
- Technical evidence (commands, exact results, artifacts):
- Deviations from packet and reasons:

## Acceptance evidence
- Preview/affected route-state-viewport evidence, or N/A with reason:
- Product/visual/release acceptance availability:
- Outcome-validation availability or measurement limitation:

## Open items
- Blockers or repository/packet contradictions:
- Remaining risks or unknowns:
- Recommended next action:
```

Keep the handoff self-contained and compact. Link evidence; include exact error lines and reproduction steps when material, but omit raw transcripts, large logs, source dumps, and repeated task context.
